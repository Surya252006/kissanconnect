Enterprise Security

8. Authentication & Security — Multi-Layer Defense

SLIDE 09
PROTOCOL 01

Stateless JWT Authentication

Cryptographic tokens verify user identity per request with strict expiration policies and token rotation.

PROTOCOL 02

Granular Role-Based Access (RBAC)

Custom middleware (`authorizeRoles`) enforces that only verified farmers can manage product listings.

PROTOCOL 03

Salted Bcrypt Password Hashing

All passwords hashed using bcryptjs with high salt rounds; plaintext passwords never touch the database.

PROTOCOL 04

Zero Client-Side Secret Leakage

Database URIs, JWT signing keys, and Cloudinary API credentials remain strictly confined to server `.env`.
